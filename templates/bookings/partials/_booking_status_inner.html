{% load wagtailcore_tags tz %} {% comment %} The payment-status poll unit — the element htmx actually replaces (outerHTML) every 2s while `booking.status` is "pending". Deliberately one level *inside* the persistent `#booking-status` aria-live="polite" region in _booking_status.html, which is never itself swapped/removed — see that file's own comment for why: A11Y FINDING 4, reviews/2026-09-22- final-accessibility-audit.md. Replacing the very node that carries aria-live on every tick is a known weak spot — some assistive technology only reliably announces mutations *within* a live region it has already registered, so a wholesale replacement of that same node risked the "payment confirmed" update going unannounced altogether (the opposite failure — a full re-announcement of unchanged text every 2 seconds for as long as the payment takes to confirm — was the other risk the old single-node version carried). Splitting the swap unit out from the live-region node avoids both: the announcer never disappears, and it only ever sees the moment the message actually changes. Polling still stops itself exactly as it did before this split: once `booking.status` is no longer "pending", this same template renders without the hx-get/hx-trigger attributes below, so there is nothing left on the freshly-swapped-in element to fire another poll — htmx's timer lives on the DOM node these attributes are declared on, and that node is exactly what outerHTML replaces each tick. Rendered directly by apps.bookings.views.booking_status (GET forms/booking/status//) for every poll response, and included once by _booking_status.html for the first load — same template, same `booking` variable, either way. Context (apps.bookings.views.booking_status / booking.html): booking a bookings.Booking, or None if the reference in the URL didn't match any booking. When present: .status (BookingStatus — pending/confirmed/cancelled/completed), .reading (a readings.Reading snippet), .start_at (UTC), .display_timezone (the IANA zone shown when the visitor booked), .public_ref {% endcomment %}
